# Naturo — Guerre des clans

Versions jouables du jeu (Windows, version de test) et son programme de mise à jour.

## Installer

1. Ouvrir la [dernière version](https://github.com/ricouhq/naturo-guerre-des-clans/releases/latest).
2. Télécharger `Naturo_Guerre_des_Clans.zip` et l'extraire entièrement dans un dossier.
3. Lancer `Naturo_Guerre_des_Clans.exe`.

Si Windows bloque le lancement, choisir « Informations complémentaires » puis « Exécuter quand même » : la version de test n'est pas signée.

## Mettre à jour

Fermer le jeu, puis lancer `Mettre_a_jour_Naturo.exe`, dans le dossier du jeu à côté de `Naturo_Guerre_des_Clans.exe`.
S'il manque, le télécharger depuis la [dernière version](https://github.com/ricouhq/naturo-guerre-des-clans/releases/latest) et le glisser dans ce dossier.

Il compare la version installée à la dernière publiée, télécharge la nouvelle, vérifie l'archive, puis remplace le jeu. Tous les joueurs d'une partie doivent avoir la même version.
